## [0.1.0] — Initial public browser-only release

- Browser-only Web Serial bench provisioner with review gates and no automatic startup-config save.
- Sanitized profile and `.env` examples with encrypted in-memory key-file handling.
- Adaptive SSH management-source list, browser-only secure plan rendering, and FAQ guidance.
- Static GitHub Pages demo with strict self-only CSP, external local `app.js` and `styles.css`, CodeQL scanning, and no application API.
