Generated configuration

Only selected port commands and an optional hostname are generated. The uploaded cheatsheet is reference material; site-specific management IPs, ACLs, RADIUS keys, SNMP, usernames, and generated platform control-plane/QoS definitions are deliberately excluded until separately templated and reviewed.

Apply sends the preview line-by-line after configure terminal, then sends end. It does not execute write memory/copy run start. Save only after verifying the result.

Browser-only secure profile

Import the non-secret JSON profile and an .env-style key file. The key file is encrypted with AES-GCM in this tab only; nothing is saved to browser storage, exported, or sent to a server.

Cheatsheet review notes
  • The tool uses the port-mode patterns from the cheatsheet: access ports with switchport nonegotiate, BPDU Guard, and unicast blocking; trunks with native/allowed VLAN configuration and switchport nonegotiate.
  • The supplied reference has a concatenated line near its housekeeping section: memory free low-watermark processor 20852logging host .... It is not applied.
  • Imported profiles can include management, ACL, AAA/RADIUS, SNMPv3, syslog, archive logging, and QoS definitions. Review every site-specific value and the redacted secure plan before applying.
  • SNMPv3 credentials are required in the imported key file when SNMP is enabled; the preview renders variable names only.
